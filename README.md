# 这是joe的个人网站，用于展示摄影作品和个人文章

## 照片管理后台

### 访问方式
访问 `admin.html` 进入照片管理后台。首次访问需要设置密码，后续访问需要输入密码验证。

### 功能说明

#### 1. 照片上传
- 支持拖拽上传或点击选择文件
- 支持多文件同时上传
- 自动上传到 postimg.cc 图床并获取链接
- 上传后照片立即显示在照片库中

#### 2. 布局编辑
- **一排三个**：适合展示多张照片的横向布局
- **一排两个**：适合展示中等数量的照片
- **一排一个**：适合展示单张重要照片
- 点击模板按钮添加布局行
- 从照片库拖拽照片到布局槽位进行排布

#### 3. 实时预览
- 在右侧预览区域实时查看最终页面效果
- 输入相册标题和文件名
- 预览效果与实际生成的页面一致

#### 4. 保存和发布
- **保存配置**：将当前配置保存到浏览器本地存储（临时保存）
- **发布页面**：生成完整的 HTML 文件并下载
- 下载后需要手动上传到 GitHub 仓库

### 使用流程

1. 访问 `admin.html` 并输入密码
2. 上传照片（拖拽或选择文件）
3. 点击布局模板按钮添加布局行
4. 从照片库拖拽照片到布局槽位
5. 输入相册标题和文件名
6. 在预览区域查看效果
7. 点击"发布页面"生成 HTML 文件
8. 将生成的 HTML 文件上传到 GitHub 仓库

### 注意事项

- API Key 已内置在代码中，由于 GitHub 仓库是公开的，请注意安全
- 配置数据保存在浏览器本地存储中，清除浏览器数据会丢失
- 生成的 HTML 文件需要手动上传到仓库才能公开展示
- 如果 postimg.cc API 调用失败，可能需要检查 API Key 是否有效

### 文件说明

- `admin.html` - 管理界面主文件
- `admin.css` - 管理界面样式
- `admin.js` - 管理界面逻辑和功能实现
- `admin-config.json` - 配置文件（当前为空，配置保存在浏览器本地存储）
